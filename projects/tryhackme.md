# TryHackMe Cybersecurity Learning Journey

## Executive Summary

This project documents my hands-on cybersecurity training through the TryHackMe platform. The learning journey focused on developing practical skills in defensive security, networking, Linux administration, web application security, vulnerability assessment, privilege escalation, and Security Operations Center (SOC) fundamentals.

Each room provided opportunities to solve realistic security challenges in a safe lab environment while strengthening technical knowledge through practical exercises.

---

# Objectives

- Build practical cybersecurity skills through guided labs.
- Strengthen understanding of networking fundamentals.
- Practice Linux and Windows system administration.
- Develop web application security testing techniques.
- Improve incident investigation and SOC analysis skills.
- Apply theoretical concepts in real-world scenarios.
