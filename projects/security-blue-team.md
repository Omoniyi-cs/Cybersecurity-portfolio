# SOC Workflow

The exercises followed a typical SOC workflow:

1. Receive security alert.
2. Validate the alert.
3. Collect relevant evidence.
4. Analyse logs and network activity.
5. Assess potential impact.
6. Recommend containment actions.
7. Document findings.
8. Monitor for recurrence.

---

# Challenges

Key challenges included:

- Distinguishing true positives from false positives.
- Correlating events across different data sources.
- Understanding unfamiliar log formats.
- Investigating alerts methodically without assumptions.

These challenges improved both my technical skills and analytical thinking.

---

# Lessons Learned

Blue Team operations require continuous monitoring, careful analysis, and effective communication. Successful investigations depend on combining information from multiple sources to make evidence-based decisions rather than relying on isolated events.

The project also reinforced the value of documentation, teamwork, and maintaining visibility across systems to support timely incident response.

---

# Recommendations

- Implement centralized logging across all systems.
- Enable Multi-Factor Authentication (MFA).
- Conduct regular vulnerability assessments.
- Keep systems updated with security patches.
- Improve endpoint monitoring and alerting.
- Provide ongoing cybersecurity awareness training.
